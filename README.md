# Machine Learning-Based Quality Prediction of Silica Concentration in a Mining Flotation Process

## Project Description

This project develops a machine learning pipeline for predicting silica concentration (%) in an iron ore flotation process using industrial sensor data. The objective is to estimate silica impurity levels before laboratory analysis, allowing earlier process adjustments and improved operational efficiency.

The study compares multiple regression algorithms to determine the most effective model for predicting silica concentration from process variables collected within a mining flotation plant.

---

## Dataset

**Dataset Name:** Mining Process Flotation Plant Database

The dataset contains sensor measurements collected from a mining flotation process, including variables such as:

* Air flow rates
* Pulp density measurements
* Flotation process parameters
* Operational sensor readings

The target variable is the silica concentration (%) in the flotation concentrate.

---

## Objectives

* Preprocess industrial process data.
* Handle missing and invalid values.
* Train multiple regression models.
* Compare model performance using standard evaluation metrics.
* Identify the most influential features affecting silica concentration.
* Visualize prediction performance.

---

## Machine Learning Models

The following regression models are implemented:

### Linear Regression

A baseline statistical model that assumes a linear relationship between input features and silica concentration.

### Random Forest Regressor

An ensemble learning model that combines multiple decision trees to improve prediction accuracy and robustness.

### XGBoost Regressor

A gradient boosting algorithm that sequentially minimizes prediction errors and captures complex nonlinear relationships.

---

## Data Processing Pipeline

The implemented pipeline follows the steps below:

1. Load dataset
2. Convert data into numeric format
3. Handle missing and invalid values
4. Separate features and target variable
5. Split data into training and testing sets
6. Apply mean imputation for missing values
7. Train machine learning models
8. Generate predictions
9. Evaluate model performance
10. Analyze feature importance
11. Visualize results

---

## Evaluation Metrics

Model performance is assessed using:

### Mean Absolute Error (MAE)

Measures the average absolute prediction error.

### Root Mean Squared Error (RMSE)

Measures prediction error while giving greater weight to larger deviations.

### Coefficient of Determination (R²)

Measures how well the model explains the variance in the target variable.
